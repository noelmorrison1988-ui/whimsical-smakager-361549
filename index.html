Discovery

Automatic YouTube discovery

EDGE now uses a server-side API connection managed by Netlify. You do not have to paste an API key on this device. Videos will play using YouTube's official embedded player.

One-time setup in Netlify: Site configuration → Environment variables → Add YOUTUBE_API_KEY, with your newly rotated key. Then redeploy this ZIP. Keep the key private and restrict it to YouTube Data API v3 in Google Cloud. API requests consume your daily quota. Discovery results are cached where supported.
